# 🎹 MIDIMax — Nopia SynthLab

> 智能和弦引擎 MIDI 控制器，将单音自动展开为和弦，通过虚拟 MIDI 端口驱动 Reaper 中的 VSTi 音源。

---

## ✨ 功能特性

### 🖥️ 运行平台
- **双模运行**：既可以直接在 Chrome/Edge 等浏览器作为 **Web 网页应用** 访问，也能打包为精简的 **Tauri 2.0 桌面客户端**（独立执行程序，低延迟、低硬件消耗，体积仅 ~10MB 左右）。

### 🎵 和弦引擎
- **调性选择**：12 个调性（C ~ B）一键切换
- **Tension 渐进**：7 级和弦复杂度（单音 → 十三和弦）
- **挂留和弦**：Sus2 / Sus4 一键切换
- **Add 模式**：三和弦 + 最高扩展音
- **V Major**：强制属和弦大调化

### 🎹 输入方式
- **实体 MIDI 键盘**：通过 WebMidi 直接接入
- **屏幕虚拟键盘**：鼠标点击演奏，支持力度响应（点击位置越靠下力度越大）
- **八度切换**：▲▼ 按钮切换键盘音域（C1 ~ C7）

### 🔀 多通道 MIDI 路由
| 通道 | 用途 | 说明 |
|------|------|------|
| CH1 | 和弦钢琴 | 和弦引擎生成的完整和弦 |
| CH2 | Bass 低音 | 根音/三音/五音（归一化到低八度） |
| CH3 | Synth/琶音 | 直通模式或琶音模式 |

### 🎼 琶音器
- 7 种速率：4n. / 4n / 4t / 8n / 8t / 16n / 16t
- ±3 八度偏移
- Legato 无缝切换和弦
- Tap Tempo BPM 同步

### 🎚️ 其他
- Bass 自动跟随（AUTO / TONE / SLOW 模式）
- Pitch Bend 弯音轮
- 转位控制（1st / 2nd / Open）
- 所有参数自动保存到 localStorage

## 🚀 快速开始

项目支持作为 **Web 浏览器应用** 或 **Tauri 桌面客户端** 运行。

### 前置要求

1. **Node.js** >= 18
2. **loopMIDI**（虚拟 MIDI 端口，Windows 用户推荐）
   - 安装命令：`winget install TobiasErichsen.loopMIDI`
   - 启动 loopMIDI，确保列表中有一个虚拟端口（默认会自动创建 `loopMIDI Port 1`）
3. **Chrome / Edge 浏览器**（如果运行 Web 版本，需要 WebMidi 接口支持，Safari 不支持）
4. **Rust 编译环境**（仅当开发或构建 Tauri 桌面版时需要）
   - 请参考 [Tauri 官方安装指南](https://tauri.app/start/prerequisites/) 配置 Rust/Cargo 环境。

### 1. 安装项目依赖

在项目根目录下执行：
```bash
npm install
```

### 2. 运行与开发

#### 🌐 方式 A：Web 浏览器版本
运行以下命令启动 Vite 开发服务器：
```bash
npm run dev
```
启动后在支持 WebMidi 的浏览器（如 Chrome/Edge）中访问控制台提示的地址（通常为 `http://localhost:5173/`）。

#### 💻 方式 B：Tauri 桌面客户端
运行以下命令启动 Tauri 桌面端开发调试：
```bash
npm run tauri dev
```
此命令将编译 Rust 后端并拉起独立的桌面应用窗口，支持热重载。

### 3. 构建与打包

#### 🌐 Web 浏览器版本打包
```bash
npm run build
```
打包后的静态资源输出在 `dist/` 目录中。

#### 💻 Tauri 桌面端打包
```bash
npm run tauri build
```
编译并生成平台原生的桌面安装包（如 Windows 下的 `.msi` 安装包及独立 `.exe` 程序），输出在 `src-tauri/target/release/bundle/` 目录下。

### 4. 配置 MIDI 设备

无论是 Web 版还是桌面客户端，运行后均需在页面顶部工具栏进行如下配置：
- **🎹 MIDI 输入** → 选择你的实体 MIDI 键盘（可选，若使用屏幕虚拟键盘则无需选择）
- **🔊 MIDI 输出** → 选择 `loopMIDI Port 1`（用于将生成的 MIDI 信号路由到 DAW 音源）

## 🎧 Reaper 配置

### 1. 启用 MIDI 输入设备

`Options → Preferences → MIDI Devices`

在 MIDI inputs 列表中找到 `loopMIDI Port 1` → 双击 → 勾选 `Enable input from this device`

### 2. 创建轨道

推荐创建 3 条轨道分别接收不同通道：

| 轨道 | MIDI 输入设置 | 用途 | 建议 VSTi |
|------|-------------|------|----------|
| 轨道 1 | `MIDI → loopMIDI Port 1 → Channel 1` | 和弦钢琴 | Kontakt / Piano One |
| 轨道 2 | `MIDI → loopMIDI Port 1 → Channel 2` | Bass | Bass 音源 |
| 轨道 3 | `MIDI → loopMIDI Port 1 → Channel 3` | Synth/Arp | Serum / Vital |

### 3. 开启监听

每条轨道：
1. 点击 **录音 Arm** 按钮（红色圆圈）
2. 开启 **Monitor** 按钮（小喇叭图标）
3. 在 FX 中加载你的 VSTi 音源

### 4. 开始演奏

在 MIDIMax 中点击钢琴键或用 MIDI 键盘弹奏 → Reaper VSTi 发声 🎶

# 🎹 MIDIMax — Nopia SynthLab 详细使用说明书

欢迎使用 **MIDIMax — Nopia SynthLab**。这是一个功能强大的智能和弦引擎 MIDI 控制器，旨在帮助音乐制作人和现场键盘手快速生成复杂的和弦进行、低音线和琶音。它采用先进的顺阶和弦展开算法，将单音输入自动扩展为丰富的和弦结构，并通过虚拟 MIDI 端口将数据多通道路由至外部 DAW（如 Reaper）中的 VSTi 虚拟乐器音源。

本说明书将为您详细解析界面上的每一个旋钮、按钮、滑块及开关的功能与使用技巧。

---

## 🎛️ 界面区域总览

MIDIMax 界面整体分为五大核心版块：
1. **顶部设备与控制栏 (Top Bar)**：用于管理 MIDI I/O 路由、时值 BPM 同步与全局弯音。
2. **和弦引擎配置区 (Tension & Harmony)**：核心算法所在，控制和弦复杂度、挂留音、加音以及调性属和弦调整。
3. **BASS 控制区 (Bass Engine)**：独立生成低音线，支持根音/三音/五音快速触发及 Sidechain 联动。
4. **SYNTH 琶音器区 (Synth / Arp Engine)**：控制直通和声或高度可调的琶音信号，支持时值速率及八度偏移。
5. **键盘与调性选择区 (Bottom Control)**：演奏核心，提供调性（主音）一键设定与虚拟键盘。

---

## 1. 顶部设备与控制栏 (Top Bar)

顶部控制栏主要处理 MIDI 信号路由、时钟速度和宏控制参数。

### 🔌 MIDI 设备选择器
在页面最上方配有三个下拉选择框：
*   **🎹 MIDI 输入**：选择您外接的实体 MIDI 键盘或 MIDI 控制器。
*   **🔊 MIDI 输出**：选择虚拟 MIDI 端口（如 `loopMIDI Port 1`），用于将和弦信号输出至 DAW。
*   **🔗 Sidechain 输入**：选择侧链信号源（可用于触发 BASS 自动跟随）。

### ⏱️ 时值与 BPM 控制
*   **BPM 显示屏兼 TAP TEMPO 按钮**：
    *   显示当前的 BPM 数值（如 `120bpm`）。
    *   **Tap Tempo 功能**：使用鼠标连续点击该显示屏，系统将根据您点击的间隔时间自动计算并同步更新当前的 BPM。双击间隔超过 2 秒时测速重置。
*   **顶部小按钮 (8 个)**：
    *   界面中部的 8 个并排小按钮为控制功能预留位（暂无事件绑定）。
*   **向左箭头按钮** (`<`)：
    *   预留功能键（暂无事件绑定）。
*   **顶部左侧双旋钮**：
    *   `topLeftKnob1` 与 `topLeftKnob2`：预留宏控制旋钮，参数已持久化。

### 🌀 弯音轮与范围拨档
位于顶部右侧，是现场演奏表情控制的核心：
*   **PitchBender (弯音轮滑块)**：
    *   垂直拖动可改变弯音值（范围：`-1` 到 `+1`）。松开后会自动弹回中心位置。
*   **白色小拨档开关 (Pitch Bend Toggle Switch)**：
    *   **向上（开启 - 绿色亮起）**：启用大范围弯音。此时弯音范围自动设置为 **5 个半音**。
    *   **向下（关闭 - 灰色）**：普通弯音模式。弯音范围自动限制在 **2 个半音**。当关闭时，弯音值会自动重置归零。
    *   *注：弯音信号会同时广播至 MIDI 通道 CH1、CH2 和 CH3。*

---

## 2. 和弦引擎配置区 (Tension & Harmony)

该区域位于界面中央，是 Nopia 智能和弦展开算法的灵魂。

### 🎚️ Tension 大旋钮 (和弦复杂度)
*   **控制项**：位于中心的大旋钮（支持垂直拖拽）。
*   **功能**：调节和弦的复杂度（级数范围为 `1 ~ 7`，共 7 级步进）。
*   **各等级音程构成（以 C 为根音为例）**：

| Tension 等级 | 对应和弦类型 / 音程构成 (半音偏差) | 示例和弦 (以 C 为根音) | 听感特点 |
| :--- | :--- | :--- | :--- |
| **Level 1** | `[0]` 纯根音 | C | 单音，无和声色彩 |
| **Level 2** | `[0, 4]` 根音 + 三音 | C-E | 空灵，省略了五音，调性明确 |
| **Level 3** | `[0, 4, 7]` 基础三和弦 | C-E-G | 经典、饱满、最基础的协和音响 |
| **Level 4** | `[0, 4, 7, 11]` 七和弦 | C-E-G-B (Major 7th) | 爵士、都市、柔和的色彩 |
| **Level 5** | `[0, 4, 7, 11, 14]` 九和弦 | C-E-G-B-D (Major 9th) | 现代、宽广、具有飘逸感 |
| **Level 6** | `[0, 4, 7, 11, 14, 18]` 十一和弦 | C-E-G-B-D-F# (Major 7th #11) | 悬念、华丽、极具张力 |
| **Level 7** | `[0, 4, 7, 11, 14, 18, 21]` 十三和弦 | C-E-G-B-D-F#-A (Major 13th) | 极其丰富、复杂的现代爵士和声 |

*注：和弦的音程构成会根据下方选定的音级属性（大/小/减/属）自动调整。例如在小三和弦（Minor）下，三音会自动降半音 (`4 -> 3`)。*

### ➕ Add 模式按钮 (加音模式)
*   **控制项**：`Add` 按钮。
*   **功能**：一键切换“三和弦 + 最高扩展音”的排列模式。
*   **工作机制**：
    *   当开启 `Add` 模式且 Tension 大于 3（即 5/6/7 级和弦）时，引擎会自动过滤掉中间的七音、九音等，仅保留**基础三和弦**加上**当前的最高张力音**。
    *   例如：在 Level 5 (九和弦) 时，标准和弦是 `[1, 3, 5, 7, 9]`；开启 `Add` 后，和弦会被精简为 `[1, 3, 5, 9]` (即 add9 和弦)。这能够有效避免声部堆叠过于拥挤，使音响效果更加清亮、透彻。

### 🔄 Sus2 / Sus4 按钮 (挂留和弦)
*   **控制项**：`Sus2` 和 `Sus4` 按钮。
*   **功能**：挂留音切换。
*   **工作机制**：
    *   激活 `Sus2` 时，会将和弦中的三音替换为大二度音（半音差 2）。
    *   激活 `Sus4` 时，会将和弦中的三音替换为纯四度音（半音差 5）。
    *   再次点击已选中的挂留按钮，即可取消挂留，恢复标准和弦的三音。

### ⚡ V Major 按钮 (属和弦大调化)
*   **控制项**：`V Major` 按钮。
*   **功能**：当按下自然调式中的第 V 级音时，强制该和弦以“大调/属和弦”属性进行展开。
*   **音乐理论背景**：在很多调式（特别是小调或特定和声进行）中，五级和弦（V）通常需要被做成大三和弦或属七和弦以提供更强烈的向主和弦（I）解决的倾向（即导音上行半音解决）。按下该按钮后，引擎遇到 V 级音时会强行将其原本的顺阶属性重写为大调（Major），使您可以轻松演奏经典的 `V -> I` 和声终结式。

## 3. BASS 控制区 (Bass Engine)

位于界面左侧，用于在 **MIDI 通道 CH2** 上触发强有力的低音信号。

### 🎹 Bass 音符触发按钮 (V / III / Root)
*   **Root 按钮**：弹下和弦的同时按下此键，会在低八度（C1 音域）触发当前和弦的**根音**（Root）。
*   **III 按钮**：在低八度触发当前和弦的**三音**（根据和弦大小调属性，自动选择大三度或小三度）。
*   **V 按钮**：在低八度触发当前和弦的**五音**（通常是纯五度或减五度）。
*   *提示：这三个按钮支持鼠标按下/抬起，可进行手动的 Bass 音源即兴弹奏。*

### 🤖 AUTO (自动 Bass 开关)
*   **控制项**：`AUTO` 按钮。
*   **功能**：激活自动低音跟随。
*   **联动逻辑**：当开启 `AUTO` 后，配合顶部的 **Sidechain（侧链）输入**，一旦侧链通道收到 Note On 信号，系统将自动触发 `Root`（根音低音）；当侧链收到 Note Off 信号时则自动停止。适用于节奏型鼓组（如大鼓 Kick）同步触发 Bass。

### 🎚️ 其它 Bass 控件
*   **TONE / SLOW 按钮**：预留功能按键（暂无事件绑定）。
*   **Bass Filter 旋钮 1 & 2**：绑定了 `bassFilterKnob1` 与 `bassFilterKnob2`，已实现参数持久化，可在外接 DAW 中通过 MIDI CC 映射为 Bass 音源的滤波器截止频率（Cutoff）或共鸣（Resonance）。

## 4. SYNTH 琶音器区 (Synth / Arp Engine)

该区域位于界面右侧，专门生成发送至 **MIDI 通道 CH3** 的合成器或琶音信号。

### 🟢 激活大拨档 (Synth On/Off Switch)
*   **控制项**：绿色垂直大拨档。
*   **功能**：Synth 模块的主开关。
*   **工作模式**：
    *   **向上拨（开启 - 绿色亮起）**：开启 Synth 发送。
    *   **向下拨（关闭 - 灰色）**：关闭该模块，CH3 不会发送任何 MIDI 信号。

### 🔀 琶音模式与直通模式
*   **直通模式 (琶音关闭)**：
    *   当 Synth 开关开启，但 `Arp` 按钮未激活时。
    *   您在键盘上弹奏的完整和弦音（经过八度偏移后）将**同步直通**发送到通道 CH3，作为长音铺底（Pad）或复音合成器音效。
*   **琶音模式 (琶音开启)**：
    *   当 Synth 开关与 `Arp` 按钮同时激活时。
    *   系统会自动将当前弹奏的和弦音符拆解，并根据设定的速度和时值，以高精度的动画帧定时器（RequestAnimationFrame）驱动，循环发送单音琶音信号至通道 CH3。支持 Legato 无缝和弦切换。

### 🎛️ Arp 控件与滑块
*   **Arp 按钮**：开启或关闭琶音器。
*   **Rate/Octave 模式切换按钮**：
    *   点击可切换横向滑块的控制模式，按钮会改变颜色以示区分：
        *   **Rate 模式（蓝色）**：控制琶音速度。
        *   **Octave 模式（红色）**：控制琶音的八度偏移。
*   **横向 Slider (滑块) 与显示屏**：
    *   **在 Rate 模式下**：滑块具有 7 级步进，可在右侧显示屏看到当前的琶音时值：
        *   `4n.` (附点四分音符)
        *   `4n` (四分音符)
        *   `4t` (四分三连音)
        *   `8n` (八分音符 - 默认)
        *   `8t` (八分三连音)
        *   `16n` (十六分音符)
        *   `16t` (十六分三连音)
    *   **在 Octave 模式下**：滑块可无级滑动（转换为 -3 到 +3 步进），控制琶音音符整体的八度偏移量（例如显示为 `Oct +1`、`Oct -2` 等），让您的琶音音域在不同的音区穿梭。
*   **Synth Resonance 旋钮**：
    *   控制 `synthResonanceKnob`，用于调节合成器共鸣参数。

## 5. 键盘与调性选择区 (Bottom Control)

位于界面底部，是设定音乐调式和直接演奏的区域。

### 🎹 Tonal Select (调性选择键)
*   **控制项**：右下角呈黑白键盘排列的 12 个独立按钮。
*   **功能**：一键切换全局调性（主音 / Tonic）。
*   **工作逻辑**：
    *   例如：点击 `C`，整个和弦引擎立即切换到 C 自然大调音阶。此时弹奏键盘的 C 键输出 C 大三和弦（一级），弹奏 D 键输出 D 小三和弦（二级）。
    *   当您在演奏中实时切换调性时，引擎会自动计算音程差，将当前正按住的和弦音无缝且不间断地“转调”过渡到新调性上，绝不出现卡音或断音。

### 🎹 虚拟钢琴键盘 (PianoKeys)
*   **功能**：用于通过鼠标直接演奏，支持力度响应（点击琴键的位置越靠下，触发的 MIDI 力度值越大）。
*   **音区控制 (▲ / ▼ 按钮)**：
    *   位于键盘左侧，用于切换键盘的全局八度音域（范围从 `C1` 到 `C7`）。
*   **转位选择按钮 (1st / 2nd / Open)**：
    *   位于键盘右侧的三个垂直按钮：`1st`（第一转位）、`2nd`（第二转位）、`Open`（开放排列）。
    *   *版本说明：这三个转位按钮在当前版本中属于 UI 视觉预留设计，尚未绑定具体的和弦转位变换逻辑。在未来的版本升级中，它们将用于一键改变和弦的声部排列方式（Voicing）。*

## 📥 参数自动保存与持久化

本合成器所有的旋钮值（如各 Filter 旋钮、Tension 值、Tonal 调性、Synth/Arp 开关状态以及滑块模式等）都通过 Pinia 状态管理库与浏览器的 `localStorage` 进行了深度绑定。这意味着**您所做出的任何微调都会被自动保存**，即使刷新网页或关闭浏览器，下次打开时依然会完美还原您上一次的个性化配置。

## 🎚️ 推荐的 DAW 多通道路由实践 (以 Reaper 为例)

为最大化发挥 MIDIMax 多通道输出的优势，建议在您的 DAW 中创建三轨虚拟乐器，分别接收不同的 MIDI 通道：

1.  **轨道 1 (和弦铺底/钢琴)**：
    *   **MIDI 输入**：`loopMIDI Port 1 -> Channel 1`
    *   **建议 VSTi**：Kontakt 钢琴、Omnisphere、Serum Pad 等。
2.  **轨道 2 (Bass 低音线)**：
    *   **MIDI 输入**：`loopMIDI Port 1 -> Channel 2`
    *   **建议 VSTi**：Trilian Bass、SubBoomBass、Serum Sub-bass 等。
3.  **轨道 3 (Synth 旋律/琶音)**：
    *   **MIDI 输入**：`loopMIDI Port 1 -> Channel 3`
    *   **建议 VSTi**：Vital、Serum 琶音音色、Massive 脉冲主音等。

配置完成后，您只需在 MIDIMax 中单指弹奏一个音符，就能同时驱动三角钢琴、律动低音和闪烁的琶音，瞬间编织出极其丰满的电子或管弦乐织体！
